## Aktuální směr potvrzený majitelem

CSS Disca postupně nahradit vlastními SCSS komponentami aSteroidu při zachování současného vzhledu a funkčnosti 1:1 na mobilu i desktopu. Kompatibilní snapshot je dočasný podklad pro nepřevedené části; pouhé zkopírování Disca není konečný stav. Používej existující mixiny a komponenty, původní HTML/třídy/události i JS Shoptetu. Převáděnou část ověřuj bez nativního CSS i bez jejích původních pravidel v kompatibilním podkladu.

Před prací na CSS načti celý [postup migrace a podmínky dokončení](docs/blank-mode.md). Součástí předání musí být evidence převedených částí a zbývajících závislostí. Neoznačuj migraci za dokončenou, dokud e-shop neprojde kontrolami bez celého kompatibilního snapshotu. Vypnutí nativního JS není součást zadání.
